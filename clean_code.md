# Code Formatting & Style Guides

## Understand the importance of code formatting and how to use tools like linters to enforce consistency.

## Why is code formatting important?

Code formatting is important because it makes code easier to read, understand, and maintain. When code follows a consistent style, developers don’t need to waste time figuring out how the code is structured. This is especially important when working in teams, where multiple people contribute to the same codebase.

Consistent formatting also helps reduce errors. Clean and well-structured code makes it easier to spot bugs and logical issues. It improves collaboration, as everyone follows the same conventions, and reduces unnecessary debates about style.

## Airbnb JavaScript Style Guide (Summary)

The Airbnb JavaScript Style Guide is a widely used set of rules for writing clean and consistent JavaScript. Some key points include:

- Use `const` and `let` instead of `var`
- Use arrow functions where appropriate
- Keep functions small and focused
- Use meaningful and descriptive variable names
- Follow consistent spacing, indentation, and line length rules
- Prefer template literals over string concatenation
