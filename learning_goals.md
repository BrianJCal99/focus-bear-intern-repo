# What Do You Want to Learn & Contribute?

## What do you hope to learn from this internship?

During this internship, I hope to learn how mobile apps are actually built and maintained in a real development team. I want to gain hands-on experience working with React and React Native and understand how projects are structured in a professional environment. I’m also interested in learning how developers collaborate using tools like Git.

## What skills are you most excited to develop?

I’m most excited to improve my front-end development skills, especially using React and React Native. I also want to get better at using Redux for managing application state and learn how to properly write tests using Jest. Another skill I want to develop is using Git more confidently when working on a team project.

## What do you think you can contribute to the team?

I believe I can contribute by being motivated, willing to learn, and open to feedback. I enjoy solving problems and figuring things out when coding, and I’m happy to put in the effort to improve my skills. I also try to communicate well with others and be supportive when working in a team environment.

## What is one area you feel less confident in that you’d like to improve?

One area I would like to improve is testing and writing automated tests using Jest. I’m also still developing my understanding of Redux and want to become more comfortable using Git when collaborating with others on the same project.

## What does success in this internship look like for you?

For me, success would be gaining real experience in mobile app development and becoming more confident with the tools and technologies used in the project. If I can finish the internship with stronger skills in React, React Native, Redux, testing with Jest, and Git, and feel more comfortable working in a development team, I would consider it a success.
