# Set up a terminal client

For my terminal setup, I primarily use Windows Terminal with PowerShell because it integrates well with Windows, supports multiple tabs, and allows easy customization. I also have Ubuntu WSL with zsh installed, since I sometimes need to work with applications in a Linux environment. Additionally, I use Git Bash, which provides a familiar Bash environment on Windows and is especially useful when working with Git repositories or running scripts that expect a Unix-like shell. This combination gives me the flexibility to handle Windows, Linux, and Git workflows efficiently.

I customized Windows Terminal by adjusting the application theme and color scheme, using both the Light and One Half Dark themes depending on the time of day and my focus needs. These visual tweaks make long coding sessions more comfortable and reduce eye strain.

The most useful command I practiced today was:

```bash
shutdown /r /t 0
```

This command immediately restarts the computer, which is handy when applying system updates or quickly resetting the environment without navigating through menus. Learning commands like this reinforced how efficient the terminal can make everyday tasks.

Overall, spending time in the terminal—whether in PowerShell, WSL with zsh, or Git Bash—has increased my confidence in using command-line tools and encouraged me to explore more commands and shortcuts that can streamline my workflow. This setup is particularly helpful when working with Linux-based development tools, Git repositories, or scripts, complementing my front-end and React/React Native work.
