# Set Up AI Tools for Development

## AI Tools I Tried

For this task, I explored multiple AI tools integrated into my development workflow.

I used GitHub Copilot, along with Gemini and Claude Code directly inside Visual Studio Code. These tools are integrated into my coding environment, which makes them convenient to use while actively writing code.

In addition, I used ChatGPT externally (in the browser) mainly for coding questions, debugging help, and concept explanations rather than inline coding.

## Experimenting with AI in Development

I used these tools in a few practical scenarios.

While coding in VS Code, GitHub Copilot, Gemini, and Claude Code helped generate code suggestions in real time. They were especially useful for writing functions, handling repetitive logic, and speeding up development. Since they are integrated into the editor, I could quickly accept, modify, or ignore suggestions without breaking my workflow.

For debugging, I found myself using ChatGPT more often. I would paste errors or code snippets and ask for explanations or fixes. This worked well because I could have a back-and-forth conversation and refine the problem step by step.

I also used ChatGPT to understand new concepts when I got stuck or wanted a clearer explanation. Compared to inline tools, it provided more detailed and structured answers.

## What Worked Well

The combination of inline AI tools and external AI worked really well together.

The VS Code-integrated tools (Copilot, Gemini, and Claude Code) were great for:

- Writing code faster
- Suggesting completions and patterns
- Reducing the need to search for syntax or boilerplate

ChatGPT worked better for:

- Debugging issues with more context
- Explaining concepts clearly
- Answering more complex or conceptual questions

This setup allowed me to stay productive while coding and still have a strong support tool when I needed deeper understanding.

## What Didn’t Work Well

There were some limitations across all tools.

Inline AI tools sometimes suggested code that didn’t fully match my intent or project context. I had to review suggestions carefully instead of accepting them blindly.

Gemini and Claude Code occasionally produced different approaches to the same problem, which could be confusing and required me to decide which one was better.

ChatGPT, when used externally, required more effort to copy-paste code and explain context, which slightly slowed things down compared to inline tools.

## When AI is Most Useful for Coding

From my experience, AI is most useful when it complements my workflow rather than replacing my thinking.

It is most effective when:

- I want to speed up writing code I already understand
- I need help debugging or identifying issues
- I’m learning something new and need quick explanations

As a developer working mainly with Frameworks and Libraries, I find AI especially useful for generating components, structuring logic, and suggesting improvements. However, I still rely on my own understanding to verify correctness and ensure code quality.
