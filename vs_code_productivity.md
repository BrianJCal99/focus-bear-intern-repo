# VS Code Shortcuts I Find Useful

I’ve been using Visual Studio Code for a while now, and it’s easily my favourite IDE. Over time, I’ve picked up a set of shortcuts that genuinely make coding faster and smoother—especially when working on frontend and React/React Native projects.

## Navigation
`Ctrl + P` → Quick open files by name
`Ctrl + Shift + O` → Go to symbol in file
`Ctrl + Tab` → Switch between open files
`Ctrl + G` → Go to specific line
`F12` → Go to definition
`Alt + Left / Right` → Navigate back/forward

## Editing
`Alt + Click` → Add multiple cursors (must-have)
`Ctrl + Alt + Down / Up` → Add cursor above/below
`Ctrl + D` → Select next occurrence of word
`Ctrl + Shift + L` → Select all occurrences
`Shift + Alt + Drag` → Column (block) selection
`Ctrl + /` → Toggle line comment
`Shift + Alt + F` → Format document
`Ctrl + Space` → Trigger IntelliSense

## Debugging
`F5` → Start debugging
`Shift + F5` → Stop debugging
`F9` → Toggle breakpoint
`F10` → Step over
`F11` → Step into
`Shift + F11` → Step out

## Terminal Commands
`Ctrl + Shift + C` → Open new terminal
`Ctrl + Shift + 5` → Split terminal
`Ctrl + Shift + W` → Close terminal
`Ctrl + Up / Down` → Scroll terminal output

## Reflection

Since I’ve already been using VS Code regularly, a lot of these shortcuts feel natural, but the ones that stand out the most in my daily work are the multiple cursor shortcuts (Alt + Click, Ctrl + D, Ctrl + Shift + L). When working on React components or styling, I often need to rename variables, update props, or edit repeated lines, and these shortcuts save a huge amount of time compared to manual edits.

Navigation shortcuts like Ctrl + P and F12 are also essential, especially when jumping between files in larger projects. In frontend development, where components are split across many files, being able to quickly open files or jump to definitions keeps my workflow smooth and uninterrupted.

Keyboard shortcuts improve productivity mainly by reducing context switching. Instead of reaching for the mouse, I can stay focused on the keyboard and keep my momentum while coding. Over time, this adds up—tasks that would normally take several steps become almost instant. It also helps reduce mental load, because once the shortcuts become muscle memory, I don’t have to think about how to perform actions, I just do them.

Overall, shortcuts make coding feel faster, more fluid, and less frustrating, which is a big reason why I enjoy working in VS Code so much.
