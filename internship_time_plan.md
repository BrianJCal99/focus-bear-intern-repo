## Week-by-Week Plan

### **Weeks 1–3: Onboarding + Foundations**

**Goal:** Build a strong foundation and get fully set up

**Week 1 (Mar 16 – Mar 20)**

* Company onboarding
* Review company policies
* Learn how the team works (Agile basics)
* Set up development tools and environment

**Week 2**

* Learn Git properly (branching, commits, PRs)
* Clean Code principles
* Start React fundamentals

**Week 3**

* Continue React fundamentals
* Learn Redux basics
* Intro to React Native
* Overview of building performant apps
* Basic debugging techniques
* Explore Focus Bear–specific libraries
* Set personal goals for the remaining internship

### **Weeks 4–11: Working on the Codebase**

**Goal:** Contribute to the Focus Bear repo and gain real dev experience

* Join the Focus Bear codebase
* Start working on issues and PRs assigned by project/group leads or the bot
* Apply what I’ve learned (React, Redux, debugging, etc.)
* Gradually take on more complex tasks
* Ask questions, get feedback, and improve workflow
* Focus on writing clean, maintainable code
* Participate in team discussions and Agile processes

### **Week 12: Wrap-Up + Handover**

**Goal:** Finish strong and document everything

* Finalise any open PRs or tasks
* Clean up and review code contributions
* Properly document work completed
* Handover tasks/projects if needed
* Reflect on learning and progress

## Summary

* First 3 weeks: learning + setup
* Next 8 weeks: real project work and contributions
* Final week: wrap-up and handover
